# Built-in ORCA Loop Packs

- release-ready: tests, architecture, hygiene, docs, security, PR readiness.
- app-store-ready: release-ready plus accessibility, screenshots, metadata, purchases, privacy.
- startup-mvp: scope cut, deployability, analytics, onboarding, docs.
- security: secrets, auth, permissions, dependency audit, threat review.
- performance: baseline, latency, bundle size, query optimization, regression checks.
- notion-hygiene: issue board sync, docs, decisions, handoffs, stale-link cleanup.

Each loop must define goal, measurement, action, stop condition, budget, handoff.
