# Install Orca 1.0

Ruby 2.6 or newer is the only runtime dependency. Choose one verified path:

- [Homebrew, release archive, PowerShell, or source install](docs/install.md)
- [Compact technical path](docs/install-for-technical-users.md)
- [Beginner path](docs/install-for-beginners.md)
- [Install validation](docs/install-validation.md)
- [Troubleshooting](docs/install-troubleshooting.md)

After installation:

```sh
orca version
orca dashboard
```

Then complete the [first evidence-backed workflow](docs/first-workflow.md).
