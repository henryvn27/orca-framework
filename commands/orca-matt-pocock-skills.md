# orca-matt-pocock-skills

## Purpose

Route ORCA work into Matt Pocock Skills when the task needs stricter engineering feedback loops, vertical slicing, domain language, or handoff discipline.

## When To Use

Use when the user asks for Matt Pocock Skills directly, or when ORCA work would benefit from a tight bug loop, TDD tracer bullet, agent-ready issue split, PRD synthesis, domain glossary/ADR pass, architecture deepening pass, or session handoff.

## Workflow

1. Open `integrations/matt-pocock-skills.md`.
2. Pick one upstream skill path, not the whole pack.
3. Keep ORCA responsible for tracker context, approval gates, branch/PR hygiene, QA evidence, and receipts.
4. Record the upstream route in the ORCA artifact or handoff.

## Output

- chosen Matt Pocock Skills route
- ORCA next action
- proof loop or artifact path when the route creates one

## Related Commands And Skills

- Commands: `orca-build`, `orca-review`, `orca-regression-task`, `orca-spec`, `orca-plan`, `orca-delegate`
- Skills: `orca-matt-pocock-skills`, `orca-attribution`
