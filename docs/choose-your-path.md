# Choose Your Path

Every path begins with a Mission. Pick an optional helper only when it reduces the work required to prove a criterion.

| Situation | Product path | Optional helper |
| --- | --- | --- |
| I want to see the product work | Run [Mission Control Demo](demo.md) | none |
| I am brand new | Complete [First Workflow](first-workflow.md) | [Beginners Guide](guides/beginners-guide.md) |
| I have a concrete repository task | Create criteria with [Quickstart](quickstart.md) | `orca-spec`, `orca-plan`, `orca-build`, `orca-review` |
| My request is still vague | Create a Mission for the decision or artifact needed | `orca-onboard`, `orca-research` |
| I am moving off GStack or GSD | Keep the outcome and evidence in a Mission | [Migration Guide](guides/from-gstack-or-gsd-to-orca-framework.md) |
| I need controller or subagent work | Keep one parent-owned Mission | `orca-controller`, `orca-delegate` |
| I need unattended progress | Bound it with Mission criteria and blockers | `orca-background`, `orca-keep-going` |
| I inherited a legacy system | Make the audit or modernization slice the Mission outcome | `orca-legacy` |

The helper may change how work is performed. It never changes what must be proved before the Mission can complete.
