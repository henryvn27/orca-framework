# Example MCP Server Review

## Server

GitHub MCP server

## Intended Use

Read and update GitHub issue and Project context for ORCA Framework work.

## Trust Decision

Allowed with constraints.

## Constraints

- issue and Project updates must stay within the active work item
- broad project changes require approval
- account, team, or permission changes are approval-required

## Registry Note

Record exposed tools, permission scope, review date, and audit expectations in `registry/mcp-servers/github.md`.
