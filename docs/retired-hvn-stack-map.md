# Retired HVN Stack Map

`hvn-stack` is retired. Useful content moved into the catalog or standalone repos.

## Standalone Repo

- `commands/orca-app-store-preflight.md`, `skills/orca-app-store-preflight`, Apple release docs, and submission templates moved to `https://github.com/henryvn27/apple-release-preflight`.

## Catalog Entries

- Work management: `notion-hvn-dashboard`
- Agent runtimes: `codex`, `claude-code`
- Workflow skills: `caveman`, `impeccable`, `superpowers`, `efficient-frontier`, `visual-plan`, `visual-recap`
- Code/repo workflow: `github-flow-manager`
- Design/UI: `anti-ai-ui`
- QA: `playwright`, `ios-simulator-mcp`, `xcodebuildmcp`
- Deployment/backend/product tools: `vercel`, `supabase`, `firebase`, `stripe`, `revenuecat`, `sentry`, `posthog`
- Apple release ops: `apple-release-preflight`, `app-store-connect`, `testflight`, `fastlane`

## Not Moved As Source

- `dashboard/orca-progress.html` and `dashboard/orca-feature-review.html` were transitional review dashboards. Their useful function is now the catalog/picker direction, not a separate repo.
- `docs/workflow-stack.md`, `docs/tool-stack.md`, and `docs/notion-system.md` were converted into catalog entries and this map.
