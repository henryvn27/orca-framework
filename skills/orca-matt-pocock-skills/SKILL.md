# ORCA Framework Matt Pocock Skills Wrapper

## What This Skill Is

A wrapper skill that routes ORCA work into Matt Pocock Skills while ORCA keeps workflow governance, attribution, approvals, QA evidence, and receipts.

## Trigger

Use when the user asks for Matt Pocock Skills, or when the task needs a tight bug loop, TDD tracer bullet, agent-ready issue split, PRD synthesis, domain glossary/ADR pass, architecture deepening pass, or compact handoff.

## Do Not Trigger

Do not use for deprecated upstream skills, personal writing/vault skills, or routine work where ORCA's native workflow already gives enough structure.

## Required Inputs

- target work item or repo task

## Exact Workflow

1. Open `integrations/matt-pocock-skills.md`.
2. Pick the single narrow upstream skill route.
3. Confirm whether the active harness has that upstream skill installed.
4. Keep ORCA artifacts in sync when the route changes spec, plan, QA, review, or handoff state.
5. State clearly that ORCA is wrapping Matt Pocock Skills, not vendoring or renaming them.

## Expected Outputs

- wrapper route
- ORCA next step
- proof loop, issue/PRD, ADR, or handoff path when produced
